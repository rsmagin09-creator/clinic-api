Clinic API — запись в поликлинику «Шипагер»

REST API на Laravel 13 · версия v1 · базовый адрес http://127.0.0.1:8000/api/v1
АутентификацияСпециальностиВрачиЦены (₸) График работыЗаписи на приёмМедкнижкаАдминистрирование
Аутентификация: Laravel Sanctum, заголовок Authorization: Bearer <token>; токен выдаётся в /login и /register. Все запросы — с заголовком Accept: application/json. Ошибки возвращаются в едином формате {"message": "..."}, ошибки валидации дополнительно с errors.
Роли: гость, patient (пациент), doctor (врач), admin (администратор). Тестовые учётные записи (пароль password): admin@clinic.ru, doctor@clinic.ru, patient@clinic.ru.

Цены (₸)

Все цены — целые числа в тенге. У врача поле price — стоимость приёма; в записи на приём price фиксируется в момент записи. Поле price_formatted — строка вида «9 000 ₸». В статистике добавлены revenue и revenue_formatted — выручка за завершённые приёмы.

Прейскурант. Параметры: specialty_id, search, price_min, price_max, sort (name, price), order.
